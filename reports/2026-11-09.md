### 1. OpenAI, 1,250억 달러 평가로 110억 달러 추가 자금 조달 성사

OpenAI가 약 110억 달러 규모의 신규 자금조달을 완료했다고 Bloomberg가 보도했습니다. 기업 가치는 **1,250억 달러**로 선정되었습니다. 기존 목표였던 300억 달러 / 1,400억 달러 가치보다 크게 하향 조정된 결과입니다. 일부 대형 투자자들이 추가 투자 규모를 축소했던 것으로 알려졌습니다. 한편 같은 날 Anthropic도 S-1 등록을 마치고 나스닥 상장(티커: ANT)을 준비 중이나, AI 주식 매도장세로 인해 예상 가치가 **2,000억 달러에서 1,200~1,300억 달러** 수준으로 재평가되고 있습니다.

| 구분 | OpenAI | Anthropic (예상) |
|------|--------|------------------|
| 평가금 | $1.25T | $1.2~1.3T |
| 자금조달 | $11B | ~$80~100B 목표 |
| 상장시장 | 미정 | 나스닥 (ANT) |

> **왜 중요한가?** AI 산업이 과열된 평가에서 조정 국면에 접어들고 있음을 보여주는 분기점입니다.

### 2. Mistral, 1조 파라미터 MoE 모델 "Le Chonk" 오픈 웨이트 공개

프랑스 AI 스타트업 Mistral AI가 **Mistral Large 4**(별칭: Le Chonk)의 가중치를 Hugging Face에 공개했습니다. 총 **약 1조 (1T) 파라미터**, 활성 파라미터 약 50B, **100만 토큰 컨텍스트 윈도우**를 갖춘 네이티브 멀티모달 MoE 아키텍처입니다. 유럽 인프라에서 처음부터 학습되었으며, MIT 변형 라이선스로 무료 사용·수정·파인튜닝이 가능합니다. API 가격은 $0.70 입력 / $2.10 출력 (Million tokens 기준).

> **왜 중요한가?** 단일 공개 모델로서 가장 큰 파라미터 수를 기록하며, 오픈소스 생태계의 규모 경쟁이 본격화되고 있습니다.

### 3. Revolut, Claude Code에서 중국산 GLM으로 90% 비용 절감하며 자사 호스팅 전환

핀테크 기업 Revolut은 약 **2,000명의 엔지니어**를 Anthropic의 Claude Code 및 OpenAI Codex에서 Z.ai의 **GLM 오픈웨이트 모델**로 전면 전환했다고 발표했습니다. 자체 US 인프라(약 56대 Nvidia B200 GPU)에서 모델을 호스팅하며, API 비용이 **약 90% 절감**(기존 대비 1/10 수준)되었고, 코드 작성 시간도 60%, 리드타임도 70% 단축됐다고 밝혔습니다.

> **왜 중요한가?** 대형 클라우드 LLM 의존에서 자체 호스팅 오픈웨이트 모델로의 대규모 전환 사례로, AI 비용 혁신의 현실성을 보여줍니다.

## 📄 Notable Papers

### GPT-6 Cyber: AI 에이전트가 발견한 948개 Linux 커널 익스플로잇 + 81개 Firefox 취약점

OpenAI가 제한된 보안 고객 대상(GPT-6 Astra 기반)으로 출시한 보안 전용 모델이, **약 12시간 동안 약 7%의 리눅스 커널**을 분석해 **2,308개 후보 버그**, 그중 **1,724개 재현**, **948개 실제 루트 익스플로잇**과 **81개 미지의 Firefox 고위험 취약점**을 발견했습니다. 총 API 사용량은 $121만 불($1,279/익스플로잇). 61개는 이미 패치됨.

> **한 줄 요약:** AI가 자체적으로 운영체제 제로데이를 찾아내는 시대가 열렸으나, $1,279/ 취약점의 비용과 윤리적 리스크가 과제로 남았다.

### MXCode: FP4 하드웨어 호환 초저비트 2bit 벡터 양자화 프레임워크

Memory capacity 및 bandwidth 한계를 극복하기 위해 **약 2bit 벡터 양자화**를 MicroXscaling-native FP4 연산과 연결하는 새로운 프레임워크가 발표되었습니다. PostScale 전략을 통해 native hardware acceleration과의 호환성을 확보해, 대규모 LLM 추론 비용 절감 가능성을 열었습니다.

> **한 줄 요약:** 양자화와 하드웨어 가속의 간극을 막는 핵심 연구로, 향후 LLM 운영 비용 구조를 바꿀 잠재력이 있다.
